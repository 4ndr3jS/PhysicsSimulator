🌈 Dispersion & Prism

See how white light splits into a rainbow through refraction

Difficulty: ● Easy

📐 Physics Formulas
n₁sin(θ₁) = n₂sin(θ₂)
Snell's Law of Refraction
n(λ) = A + B/λ²
Cauchy's Equation (simplified)
δ = (n-1)A
Deviation angle (thin prism)
📚 Key Concepts
  • Different wavelengths refract at different angles
  • Violet light bends more than red light
  • Refractive index depends on wavelength
  • Prism angle affects dispersion amount
  • Material determines how much light disperses
🔬 Try This
  • Change the prism angle and see the effect
  • Try different light sources (white vs colored)
  • Increase refractive index for more dispersion
  • Rotate the prism to change incident angle
  • Use rainbow mode to see full spectrum
