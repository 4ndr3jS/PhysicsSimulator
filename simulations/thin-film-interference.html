Wavelength in the film
📚 Key Concepts
  • Phase shift occurs at denser medium boundary
  • Path difference = 2 × thickness × refractive index
  • Different wavelengths interfere differently
  • Thickness determines which colors appear bright
  • White light creates rainbow patterns
🔬 Try This
  • Vary thickness to see color changes
  • Change refractive index (soap vs oil)
  • Switch to monochromatic light mode
  • Enable wedge mode for rainbow gradient
  • Watch colors change with viewing angle
